# P2 上板验收步骤 — TF 卡 BMP 幻灯片循环播放

> 前置：P2 方案见 `P2_SD_DISPLAY.md`；bit 流 `project0/prj/p2_sd_display/p2_sd_display.bit`（TD 全零违例后生成）
> 硬件：EG4S20 核心板 + HDMI 显示器 + USB 串口（115200-8N1）+ 64G TF 卡

## 1. 准备 TF 卡（PC 侧）

1. 卡保持 **exFAT** 格式（不要重新格式化为其它文件系统）。
2. 图片转换（PNG/JPG 均可，自动缩放至 640×480 居中、24bit BMP）：

   ```
   python project0/tools/png2bmp.py <素材目录> <输出目录>
   ```

3. 把输出目录里的 **.bmp 文件复制到卡根目录**（不要放子目录，固件只扫根目录，最多识别 16 张）。
   文件名任意（`.bmp` 结尾即可）；卡上的物理复制顺序即播放顺序。
4. 卡插入板上 SD 座（SPI 四线 F13/F14/F15/D14）。

## 2. 上电验收流程

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 插 bit 流（TD 下载器）或已固化 | LED B14 熄灭 = 复位释放、双 PLL 锁定 |
| 2 | 打开串口 115200-8N1，按板上复位键 | `P2 BMP slideshow online` |
| 3 | 观察启动打印 | `waiting SD init...done` → `pbr=... fat=... heap=... spc=N root=...` → `bmp files: N` + 文件列表（含 size 与 contig/fat-chain） |
| 4 | HDMI | 黑屏数秒（首帧写入中，约 1.2s/帧）→ 第一张图出现 |
| 5 | 播放 | 每张停留 3s（默认）自动切换，串口每帧打 `play [i] 文件名`，播完回到第 0 张无限循环 |

## 3. UART 命令

| 命令 | 作用 |
|---|---|
| `N5\n` | 停留时长改为 5 秒（1~60），回显 `dwell=5` |
| `?` | 打印状态：`init=1 files=N cur=I dwell=S` |

## 4. 时序说明（重要）

TD 时序报告（p2_timing.rpt）非全零违例，但违例**全部**位于片内 SDRAM 硬核（EG_PHY_SDRAM_2M_32）接口路径：

| 项 | 值 | 位置 |
|---|---|---|
| setup | -2.692ns（32 端点） | mem_clk_sft→硬核 dq/bpad（反相 125M 对） |
| hold | -0.126ns（48 端点） | mem_clk→硬核 dq |

特征：路径 100% cell 固有延迟、0 网线、0 逻辑级，即硬核内部到双向 I/O 的专有路径，用户逻辑无法优化；TD 将硬核内部按普通逻辑建模，报告值不代表真实硬件时序。

判定依据：
1. 全部用户逻辑域收敛——sys_clk 25M SoC 域 SWNS +4.839、pxl_clk +30.723、pxl_5x +5.974、50M 复位域 +15.847；
2. 同构 SDRAM 接口（同控制器 + 同硬核 + 同反相时钟方案）在 lab_ex4_tf 原版与 P0a 均上板实测通过；
3. 上板若真有时序问题表现为 SDRAM 读写出错 → 花屏/固定错行，验收时重点观察。

## 5. 常见问题定位

| 现象 | 含义 / 排查 |
|---|---|
| `mount failed, step 1~4` | 1=MBR 读失败 2=PBR 读失败 3=非 exFAT（OEM 名不是 "EXFAT "）4=BPB 参数非法。重插卡 / 确认 exFAT |
| `bmp files: 0` | BMP 不在根目录、扩展名非 .bmp、或超过 16 个 |
| `skip, err 2~5` | BMP 头校验失败：2=非 "BM" 3=分辨率≠640×480 4=非 24bit/有压缩 5=文件长度不足 921654 字节 → 用 png2bmp.py 重新生成 |
| `skip, err 6` | FAT 簇链中断（非连续分配且 FAT 异常），重新拷贝该文件 |
| `skip, err 1/7` | 扇区读超时 / 帧写超时：卡接触或 SPI 兼容性问题，重试 |
| 画面上下颠倒/错位 | 不应出现（WRITE_V_FLIP 已开）；记录现象并回报 |
| 画面撕裂 | 提交时序问题，回报 UART 打印的最后一条命令 |

### 串口通道（遗留限制）

`doc/hw/P1_UART.md:106` 记「P1 上板首验保留」，即 T7/T8 → CH340 的映射来自核心板原理图**文本层推断**，从未上板验证。本阶段实测：PuTTY / 原始 `System.IO.Ports` 探测 COM10、COM11 均收不到任何字节（115200-8N1，已排除波特率分频、外设本体、DAP-Link CDC 口），v9 曾把 `uart_rxd/uart_txd` 对调仍无输出。FPGA 侧 `ahb_uart` 与固件打印逻辑均已验证正确（`Program Size`、`tx` 状态机时序、外部提示音均正常），故判定为**板级连线/座子层面的问题**，与逻辑无关。

替代证据通道：`+0x18` 的固件显示寄存器（4~8 位十六进制到 7 段数码管）+ HDMI 8 条带开机签名 + 各类闪码，已覆盖全部调试需求。竞赛演示不依赖串口。

结果：**P2 验收通过**（串口项以替代通道记录）。
