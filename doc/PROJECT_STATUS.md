### 3.2 可选改进（不影响验收）

4. **载入提速**：4.07 s → 理论 1.18 s。实测 1.6 ms/扇区（理论 0.66 ms），差额来自 `sd_card_sec_read_write` 每扇区固定开销（CMD17 往返 ~2000 周期 + 数据前导等待）。可把 `S_WAIT_READ_WRITE` 的 `sec_end` 反馈提前、或让 `sd_ctrl` 预取下一扇区地址。
5. **轮播 + 音乐同时**：需把音乐素材降到 22.05 kHz 单声道（44 KB/s，加轮播 226 KB/s 合计 270 < 320 ✅）或把 SPI 提到 12.5 MHz（≈640 KB/s，需示波器确认信号完整性）。当前实现是「放音乐时暂停轮播」。
6. **P4 真·逐像素 Alpha**：需要第二个帧缓冲读口；`sdr_wrrd` 是加密 IP，只能改成「行交错双图」布局 + 两行行缓存盲调（无仿真器，风险高）。
7. **串口排查**：把 T7/T8 之外的其他可能引脚（如底板 UART 排针）逐一试；或直接用 UART2USB 座飞线。属于工程便利性，不影响演示。
8. **Keil SWD 调试**：DAP 口只引出 `SWDIO=K6 / SWCLK=K3`，但 Keil 下拉框为空（适配器未被枚举），可能是 CH32V203 的 DAP 固件/驱动问题；`CortexM0_SoC` 的 SWD 通路在 RTL 层是通的。

## 4. 复盘：这次踩过的坑（都已修，细节见 SKILL.md）

**RTL/总线**：AHB 读数据必须在**数据相**采样（`rd_rawdata` 曾用地址相 → 整个扇区左移 1 字节）；同一从口里 `STATUS` 的读译码索引写错一位 → `au_level()` 恒 0 → 音乐阻塞；只写寄存器不能用「读改写」；异步 FIFO 的 used-word 计数是一条 125 MHz 临界路径（必须寄存）；32 深度寄存器堆 + 变量下标会生成巨型多路器（LUT 爆炸 + 时序崩）。

**exFAT**：BPB 偏移整体错位一格；文件名尾部 NUL 被抄进缓冲区导致扩展名判断失效；18 字符文件名的条目组会跨扇区；NoFatChain 连续文件的簇号必须 `+1`；卡可能是 superfloppy（LBA0 即引导扇区）。

**音频**：一个字必须装两个连续样本（否则半速）；立体声不能直接混单声道（相位抵消）；8 bit PWM 的量化底噪明显，sigma-delta 好 20 dB；模拟侧 2 kHz 以上被砍 10–37 dB，只能软件补偿。

**流程**：`Set-Content` 会把 UTF-8 写成 GBK（改用 `edit` / `WriteAllText` + `UTF8Encoding($false)`）；`run_p2.tcl` 的 `add_files` 必须手工登记新文件；TD 增删文件后不删 `p2_sd_display_Runs` 会报 `PRJ-8806`；器件用到 75% LUT 会布线失败（`RUN-8102`），比时序更早撞墙。
